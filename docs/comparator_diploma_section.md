# Раздел 3.3. Нейросетевой модуль MultiAspectComparator

В рамках дипломной работы разработана модель **MultiAspectComparator** — лёгкая multi-task CNN на базе MobileNetV3 Small.

## Архитектура

- **Вход:** 4-канальный тензор 224×224 (яркость Figma, яркость сайта, карта отличий, средняя яркость)
- **Backbone:** MobileNetV3 Small (pretrained, ~1.08 млн параметров, из них обучается ~149 тыс.)
- **Голова:** 6 независимых классификаторов (overall + text + image + layout + typography + color)
- **Обучение:** синтетический датасет 5700 пар, AdamW, BCELoss (с повышенным весом на `overall`)

## Результаты обучения

| Метрика | Значение |
|---------|----------|
| Mean F1 (val) | **0.971** |
| Mean MAE | **0.027** |
| Время обучения (CPU) | **~33 мин** |

Модель выступает «умным арбитром», дополняя детерминированные методы (DOM-парсинг, EasyOCR, пиксельный diff). Гибридный подход повышает точность и читаемость отчётов о багах.
